# Module Roadmap

Phase 1 provides identity, tenancy, API conventions, and tests. Phase 2 provides salon profiles, database-backed settings, branches, working hours, and holidays. Phase 3 adds service categories, services, and staff-service mapping. Phases 4–6 add staff schedules, customers, and the heavily tested booking engine. Mobile, payments, subscriptions, notifications, marketing, reporting, and platform administration follow only after their dependent backend contracts are stable.
